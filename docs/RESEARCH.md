# Исследование интеграции

## Что удалось проверить локально

Репозиторий изначально пуст. Среда разработки — macOS ARM64. В локальном `libraryfolders.vdf` Steam и manifest-файлах нет AppId 3132990. Файлы самой Windows-версии Benchmark Tool, её INI и реальные результаты отсутствуют. Поэтому в проекте нет утверждения, что конфигурация или меню были проверены реальным прогоном на этой машине.

## Источники и принятые решения

- [Официальная страница Game Science в Steam](https://store.steampowered.com/app/3132990/Black_Myth_Wukong_Benchmark_Tool/): идентификатор отдельного бесплатного инструмента, Windows, характер real-time теста. Разработчик предупреждает, что сцена не полностью характеризует производительность полной игры.
- [Исходники интеграции Shirykalov-Ivan](https://github.com/Shirykalov-Ivan/black-myth-wukong-auto-benchmark): наблюдаемые ключи `UISettingData`, группы качества, история `b1/BenchMarkHistory/Tool`, поля `FPSAvg/FPSMin/FPSMax/FPS95/Records`. Это свидетельство автора сторонней интеграции, не спецификация Game Science. Реализация здесь самостоятельная: OCR вместо координат, журнал снимков, строгая проверка профиля, хэши и стабильность файлов. Пример исходного реального JSON из целевой установки пока не получен.
- [Исследование krsnvv](https://github.com/krsnvv/WukongBenchmarkRunner): дополнительные сведения о launcher/Shipping-процессе, `Rtx`, `InsertFrame`, значении `RtxLevel=2`. Этот автор не подтвердил постоянный текстовый путь FPS на своей установке; это дополнительный повод не считать путь истории универсальным контрактом.
- [Microsoft: D3D12 OPTIONS5](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/ns-d3d12-d3d12_feature_data_d3d12_options5): проверка реального `RaytracingTier` выбранного адаптера.
- [Microsoft: Windows OcrEngine](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine): английское распознавание строк и координат слов используется для управления меню; FPS извлекаются из истории.

## Изолированные точки неопределённости

| Компонент | Что проверить при смене версии |
|---|---|
| BenchmarkConfigManager | активный путь INI, ключи и шкалы UISettingData, ScreenMode, render height, upscaler enum, RT level |
| BenchmarkUiDriver | надписи главного меню и подтверждения, дополнительные диалоги, распознавание при SDR/HDR |
| BenchmarkProcessSession | launcher и дочерний EXE, передача аргументов Unreal/Steam, фактический выбор GPU |
| BenchmarkRunner.HistoryDirectories | фактический каталог истории, создание файла именно после окончания сцены |
| BenchmarkResultParser | JSON поля FPS, шкала ImageQuality и представление ScreenResolution; завершённость Records |

`ApplicationInspector` сохраняет инвентаризацию локальных файлов до/после запусков. Оригинальные INI остаются в backup, запрошенные и записанные приложением настройки — в каталоге отчёта. Поэтому адаптер можно исправить по данным конкретной установки, не меняя остальную архитектуру.

## Проверка на Windows перед сдачей

1. Собрать и выполнить тестовый проект. Запустить с обычным SDR экраном, установленным английским OCR и авторизованным Steam.
2. Проверить поиск в основной и дополнительной Steam Library; сравнить путь с manifest AppId 3132990.
3. Проверить запуск с отсутствующим конфигом и с существующим; сохранить реальные INI до/после. Сопоставить экран графических настроек с профилями, особенно render scale и разрешение. Проверить, что команда выбора GPU применяется к нужному адаптеру.
4. Для CPU и GPU сравнить числа отчёта с экраном результата и `result.raw.json`. Подтвердить, что новый JSON действительно создаётся только после полного окончания сцены.
5. Проверить RT на адаптере с DXR и отключение на адаптере без DXR; сверить RT/FG/масштаб из истории. Если приложение меняет профиль, отчёт должен помечать прогон ошибкой.
6. Прервать во время запуска и во время сцены через Ctrl+C; сверить SHA-256 оригинальных файлов. Повторить после принудительного завершения утилиты, закрыть оставшийся процесс и выполнить `--recover-only`.
7. Проверить неизвестный экран/тайм-аут/сбой приложения: ненулевой код выхода, сохранённые диагностика и backup, отсутствие вымышленных FPS и восстановление конфига.

Этот список — оставшаяся интеграционная валидация, а не журнал якобы выполненных прогонов.
